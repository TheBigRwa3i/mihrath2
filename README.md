# درع المزارع — Farmer’s Shield

مخطط الدورة الزراعية والمناخ الذكي للمزارع الأردني. واجهة عربية RTL باستخدام HTML وTailwind CSS وVanilla JavaScript.

الموقع المنشور: https://farmers-shield-jordan.jauntyfrog2.chatgpt.site

## التشغيل السريع

افتح `index.html` مباشرةً في متصفح حديث. لا تحتاج إلى تثبيت مكتبات أو API Key.
التصميم والخط العربي وبيانات NASA الاحتياطية مضمنة داخل الملف، لذلك يستمر التحليل دون إنترنت. الاتصال بالواجهات الحية يحتاج الإنترنت؛ توقع الطقس الاحتياطي مثال تجريبي وموسوم بذلك.

للمعاينة عبر خادم محلي، من مجلد المشروع شغّل:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

ثم افتح http://127.0.0.1:8765/index.html . على Windows يمكن استخدام `py` بدل `python3`.

## الملفات

- `index.html`: التطبيق الكامل الجاهز، ملف واحد مستقل.
- `dist/index.html`: النسخة نفسها المعدة للنشر على استضافة ملفات ثابتة.
- `src/index.template.html`: هيكل الصفحة والعناصر العربية.
- `src/styles.css`: التصميم المتجاوب وتنسيق الطباعة.
- `src/app.js`: المدخلات، API، الحسابات، المحاكاة، التقويم والتنبيهات.
- `data/`: ردود NASA POWER الأصلية للمفرق والأغوار الوسطى وإربد، جُلبت في 14 نوفمبر 2026.
- `assets/`: Tailwind CSS 2.2.19 والخط العربي Noto Sans Arabic.
- `build.py`: دمج المصدر والأصول والبيانات في ملف HTML مستقل.
- `tests/`: اختبارات المتصفح وعينة توقع تاريخية للاختبار وسجل التحقق السابق.
- `licenses/`: تراخيص الخط وTailwind.
- `.openai/hosting.json`: تعريف الموقع الحالي في Sites. لا يتضمن بيانات اعتماد.

## التعديل وإعادة البناء

عدّل الملفات داخل `src/` ثم شغّل:

```sh
python3 build.py
```

يعيد ذلك إنشاء `index.html` و`dist/index.html`، دون تنزيلات أو اعتماديات Python إضافية.
ملفات `src/` قوالب تطوير، وفيها علامات يتم استبدالها وقت البناء؛ افتح ملف `index.html` الناتج لتشغيل التطبيق.
إذا عدلت الاحتياطي المناخي، حافظ على بنية الرد والوحدات وحدّث تاريخ توثيق البيانات في المصدر.

## الاختبارات الاختيارية

تشغيل التطبيق لا يحتاج Node.js. لتشغيل اختبارات التطوير تحتاج Node.js وnpm وPython 3:

```sh
npm install
npx playwright install chromium
npm run serve
```

اترك الخادم يعمل، وافتح نافذة Terminal ثانية في المجلد نفسه:

```sh
npm test
```

تكتب الاختبارات لقطات وفحص الطباعة والنتائج في `tests/output/`. تختبر الحسابات، السيناريوهات، 144 تركيبة من المنطقة والموسم والمحصول والري، البيانات المفقودة، تأخر API، تبديل المناطق، الهاتف والعمل دون إنترنت. ملف التوقع في `tests/fixtures/` عينة اختبار فقط؛ تُكيّف تواريخه داخل الاختبار ولا تُستخدم كتوقع حي في التطبيق.
يمكن اختيار عنوان خادم آخر عبر `TEST_URL` أو متصفح مثبت عبر `CHROME_EXECUTABLE_PATH`.

## النشر والمشاركة

ارفع `dist/index.html` إلى استضافة ثابتة تدعم HTTPS. لا توجد قاعدة بيانات أو خادم تطبيق أو أسرار مطلوبة. عند إنشاء موقع مستقل في Sites استخدم هوية جديدة بدل إعادة استخدام هوية الموقع الحالي.

## مصادر البيانات وحدود النموذج

- NASA POWER: https://power.larc.nasa.gov/docs/methodology/data/sources_hydrology/
- Open-Meteo: https://open-meteo.com/en/docs — بيانات التوقع وفق CC BY 4.0، مع نسب المصدر داخل التطبيق.
- ERA5: https://open-meteo.com/en/docs/historical-weather-api — إعادة تحليل تاريخية، وليست توقع المستقبل المستخدم هنا.
- FAO: https://www.fao.org/land-water/databases-and-software/crop-information/en/

يحوّل التطبيق أمطار NASA من ملم/يوم إلى ملم/شهر، والرياح إلى كم/ساعة، والإشعاع إلى MJ/m²/day. رطوبة GWETTOP وGWETROOT مؤشرات نموذجية بلا وحدة وليست قياسات SMAP مباشرة. FAO GAEZ وSMAP وMODIS/ECOSTRESS مراجع موضحة وليست مصادر API إضافية موصولة.
المعادلات ومعايير المحاصيل تقديرية للتخطيط، ولا تستبدل فحص التربة أو الرصد المحلي أو إرشادًا زراعيًا متخصصًا. التوقع الاحتياطي اصطناعي وموسوم بوضوح. حدود النموذج ومصادره معروضة داخل التطبيق أيضًا.
